Вайбкодер. Собираю рабочие приложения в [Cursor](https://cursor.com): описываю, что должен увидеть человек, агент пишет код, я проверяю на телефоне и в браузере.

Штуки, которыми пользуются: ученики автошколы, инструктор, я сам каждый день.
